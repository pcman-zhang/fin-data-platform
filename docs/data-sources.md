# 数据源

> 本文记录各数据源的**当前状态、能力边界与已知问题**，以及复权数据的对账结论。
> 接入方式与配置见 [配置手册](configuration.md)；跨源合成策略见 [核心组件](components.md)。

状态标记：✅ 可用 · ⚠️ 有条件可用 · ❌ 特定能力不可用

## 1. 概览

| 源 | 接入方式 | 凭证 | 费用 | 定位 | 状态 |
|---|---|---|---|---|---|
| Tushare | Python 库 | Token | 免费 | 主源：股票 / 基金 / 指数 / 财务 / 事件 | ✅ |
| AkShare | Python 库 | 无需 | 免费 | 免凭证补充源 | ✅ |
| Wind | 远端 MCP（HTTP JSON-RPC） | API Key | 付费 | 宏观 / 快照 / 债券 | ✅ 能力有限 |
| iFinD | 远端 MCP（HTTP JSON-RPC） | Authorization | 计费（按调用） | 基金 / 指数 / 宏观聚合 | ✅ 能力有限 |
| Fuyao | REST | API Key | 免费 | 快照主力；行情 / 参考补充 | ⚠️ 原生复权不可用 |
| BaoStock | Python 库 | 无需 | 免费 | 股票 / 指数补充；因子源 | ✅ 仅沪深两市 |

Wind 与 iFinD 通过厂商远端 MCP 接入，**无需安装厂商 SDK**。

## 2. 通用机制

- **显式来源**：所有请求必须指定 `source`，作为主源；主源语义不因补全而改变；
- **跨源合成**：主源缺字段时按策略补全；不可信原生复权时以「原始价 + 因子」合成；
  主源失败时按配置回退；结果标注实际执行源；
- **调用约束**：每源独立限流（令牌桶）；进程内 TTL 缓存；调用计量与预算告警；
- **费用意识**：源与能力标注费用属性（免费 / 付费 / 计费）；计费能力默认优先合并调用、
  缓存与按需触发（调用次数即成本）；
- **对账纪律**：数据源的能力声明不等于可信——新源或新接口上线前须通过对账
  （方法见 §4），未通过的能力不进入可信路由。

## 3. 各源详情

### 3.1 Tushare ✅

- **能力**：日线行情（按资产类型路由：股票 / ETF-LOF / 指数）、复权因子
  （股票与基金分接口）、场外基金净值、参考数据（股票 / 基金 / ETF / 退市 /
  分类 / 指数列表）、标的与基金指数基础信息、指数成分权重（月度快照）、
  财务（核心列）、市场事件（新股 / 停复牌 / ST / 更名）、交易日历；
  **基础信息同时用于平台全市场登记**（`ref.entity` 身份 + 上市/退市区间）；
- **状态**：默认主源；也是默认复权因子源（对账基准）；费用：免费；
- **调用约定（指数与复权）**：复权只对个股类标的（股票 / ETF / LOF）有意义；
  指数是编制结果序列（分红除权由指数编制规则处理，全收益口径对应全收益指数），
  不存在价格复权概念。请求指数复权时平台**显式拒绝并报错**，而不是静默返回
  原始价——静默会制造"已复权"的错觉，是更危险的错误；
- **已知问题**：
  - 各接口可用范围与频次不同，由库内限流与预算配置约束；
  - 财务接口按核心列收敛（完整报表字段随后续数据集扩展）。

### 3.2 AkShare ✅

- **能力**：日线行情（股票 / ETF / LOF / 指数，支持前复权 / 后复权）、
  快照（股票 / ETF / LOF）、场外基金净值、交易日历；
- **状态**：免凭证可用；行情 / 净值为单标的形式，多标的请求由库自动拆分合并；
  快照为**全市场 spot 接口**（一次调用取全市场，按请求代码本地过滤）；
- **已知问题**：
  - 快照暂不支持指数（`stock_zh_index_spot_em` 需按系列调用，且覆盖不稳定）；
  - 快照 `volume` 按「手 → 股 ×100」换算（与其它接口口径一致）；
  - 无参考数据接口（标的列表类数据需换源）。

### 3.3 Wind ✅（能力有限）

- **接入**：远端 MCP，凭证由调用方注入；
- **费用**：付费；
- **能力**：日线行情（仅日频；单代码逐次调用）、快照（单次 ≤50 代码）、
  宏观 EDB（精确代码批量）、债券行情（长区间自动分块）；
- **已知问题**：
  - K 线为单代码接口，批量请求由库逐次调用（批量场景成本随调用次数增长）；
  - 日线接口不接受 `period` 参数；
  - 宏观指标为精确代码模式，需要指标代码表。

### 3.4 iFinD ✅（能力有限）

- **接入**：远端 MCP，凭证由调用方注入；
- **费用**：计费（按调用）；
- **能力**：K 线（**仅指数**）、场外基金净值（多基金合并为单次调用）、
  宏观 EDB（多指标聚合）、自然语言类工具支持多标的 / 多指标聚合
  （单次代码数为请求体积的安全上限）；
- **已知问题**：
  - 股票 K 线不在能力范围，股票行情需换源；
  - 自然语言类接口依赖远端解析，结果口径以对账为准。

### 3.5 Fuyao ⚠️

- **接入**：REST，Base URL 与重试次数可配置；服务按负载动态限流
  （HTTP 429 或业务错误码），库内退避重试；
- **费用**：免费；
- **能力**：快照（批量，**快照能力主力来源**；暂不配置回退）、日线行情
  （单标的，长窗口自动分块）、参考数据（股票 / 基金 / 指数列表）、
  交易日历（近一年窗口）；
- **原始价可信**：与 Tushare 基准逐日完全一致（对账窗口内 654 个交易日零差异）；
- **❌ 预计算复权序列不可用**（对账结论）：
  - 后复权日收益被系统性衰减（约 84%），前复权日收益被放大约 4%；
  - 隐含因子随当日涨跌反向变动（与原始收益相关系数约 −0.98），
    非除权日出现大量因子跳变；
  - 同日 OHLC 的复权比值不一致（标准语义下应相同）；
  - 事件乘数与理论值偏差约 −0.13% ~ +0.28%；
- **处置**：请求复权时由 Router 组合「原始价 + 因子」合成（需配置因子源）；
  直接调用该适配器仅支持 `adjust=None`。

### 3.6 BaoStock ✅（仅沪深）

- **接入**：Python 库；连接断开自动重新登录（会话按代际与引用计数管理）；
- **费用**：免费；
- **能力**：日线行情、复权序列、复权因子（仅 SH / SZ，含指数）；
- **因子可信（对账通过）**：归一化后与 Tushare 因子一致（百万分位差异），
  前复权与 Tushare 基准跨源一致；累计因子与 Tushare 仅相差常数比例
  （锚点不同，各自自洽）；
- **处置**：可作为股票因子源使用；原生复权序列不列入可信路由（统一走因子合成）。

## 4. 对账与可信度

任何源/接口进入可信路由前，须通过对账。方法（以复权为例）：

1. **原始价一致性**：与基准源逐日比对（应为零差异）；
2. **事件乘数**：除权除息日的理论乘数 vs 实测乘数（检验公司行为处理）；
3. **归一化因子**：因子归一化后应跨源一致（差异应为舍入级）；
4. **日收益回归与形态检验**：标准复权仅在除权日产生跳跃，
   非事件日因子不应随行情波动；同日 OHLC 的复权比值应一致。

| 源 | 能力 | 对账结论 |
|---|---|---|
| Tushare | 原始价 / 因子 | 基准（事件乘数与理论一致） |
| BaoStock | 因子 | ✅ 通过（归一化一致，前复权跨源一致） |
| Fuyao | 原始价 | ✅ 一致 |
| Fuyao | 预计算复权 | ❌ 未通过（不符合标准复权语义） |

## 5. 已知问题汇总

| 源 / 能力 | 问题 | 影响 | 现状处置 |
|---|---|---|---|
| Fuyao 预计算复权 | 不符合标准复权语义 | 复权序列不可用 | Router 以「原始价 + 因子」合成 |
| iFinD K 线 | 仅指数 | 股票行情需换源 | 文档标注，接入时按能力校验 |
| Wind K 线 | 单代码、无 `period` 参数 | 批量成本高 | 库内逐次调用 |
| BaoStock 覆盖 | 仅 SH / SZ | 北交所与基金不支持 | 按可用性校验后路由 |
| 限流与预算 | 进程内生效 | 多进程部署叠加请求量 | 跨进程聚合为规划项 |
